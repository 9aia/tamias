pub fn complete_with(line: &str, dynamic: &[Candidate]) -> Vec<Candidate>
Expand description

complete plus caller-supplied dynamic candidates.

Static candidates always win: dynamic entries are consulted only when the position under completion yields no static candidates and [dynamic_ok] says the verb’s arg shape has a free slot there — Free verbs at any arg position, :service at the unit position (≥2), :logs at the name position (1). The dynamic list is prefix-filtered case-insensitively against the token being completed (matching on insert minus its trailing space); the caller owns ordering, dedupe, and the size cap.
