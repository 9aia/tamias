Module ops 

Source
Expand description

Engine ops — cli.<verb> wire queries dispatch into the cuora engine lib through this binary’s own run verb: each call re-execs tamias-driver-cuora run <argv> with the request’s params mapped to cuora’s globals, so cuora::dispatch writes to the child’s captured stdout and never touches the serve loop’s ndjson stream — and every mutation keeps the engine’s own semantics (config search, audit events, guardrails).

ops answers the ops manifest as JSON — derived from the engine’s own clap tree ([cuora::command]), so a verb can’t exist on the CLI and be missing here: declared args become typed params (arg/opt/flag), doc strings ride along unchanged.

cuora has three verbs that can never be request/response ops — they ride run passthrough / generated-surface subcommands (inherited stdio) instead, and are listed in surfaces:

  • serve — the unbounded ndjson IPC loop; it never returns.
  • put/rotate — bounded, but the secret value enters via stdin or a hidden /dev/tty prompt, never argv (args land in shell history and /proc). A wire op child (Command::output) has no usable stdin, so these verbs can only ever fail as ops. A params-stdin channel is org task T-008 — until it lands, secret entry stays on the streaming surfaces where stdin is inherited. No param ever carries a value: put/rotate take only the cuora:// ref.

mutates is honest: init writes the identity + verifies the vault, rm/migrate/deploy rewrite vault or sink state, and run spawns arbitrary child processes — side effects beyond engine-state writes, so it gates like a mutator. get/env materialize values into captured stdout (callers must treat op output as secret); list/check/manifest/schema only read. Streaming flags would join SKIP_PARAMS — none exist today.

Constants§

MUTATES 🔒
Verbs with side effects beyond reads — vault/identity/config writes (init/rm/migrate/deploy) and arbitrary child exec (run). Mutators belong behind a deliberate trigger, not ambient view polling.
SKIP_PARAMS 🔒
Params excluded from ops — flags that turn a bounded verb into a stream, or params that must never ride argv. None today: secret values are never params (stdin/prompt only).
SURFACES 🔒
Unbounded surfaces — verbs that never return (serve), plus the stdin-bound secret-entry verbs (put/rotate, see module docs). They can never be request/response ops.

Functions§

argv 🔒
cli.<verb> params → cuora argv (no argv[0] — run prepends it). Globals come first: config resolves to --config, and env/actor/json map to the CLI’s globals by hand — clap globals never appear in a subcommand’s get_arguments(), so the param loop below can’t see them (same trick as mimus’s --format). Declared params map by kind — positionals land last, in schema order.
kind 🔒
A clap arg → the manifest’s typed param kind — arg = positional, opt = --name <v>, flag = --name — the contract pavo-driver-kit’s surface layer renders args from.
manifest
The ops query/ops argv verb payload — self-describing so hosts and agents discover the engine surface without argv help. config/env/actor/json are cuora’s globals — accepted by every op, listed once on the manifest itself; config is driver-resolved and handed to the child as --config.
op_cmd 🔒
op_of
Is query an engine op (cli.<verb>)? Returns the verb name.
param_json 🔒
run_verb
Run one engine op by name: re-exec run in a child with captured output, and hand back {op, argv, code, stdout, stderr} as the query payload. ok:false is reserved for spawn failures — a nonzero code is the engine’s own exit status (e.g. check findings), honest data. The child’s stdin is null: secret-entry verbs (put/rotate) are surfaces, never ops, precisely because they need it.
scalar 🔒
A wire scalar → its argv token (numbers/bools stringify).
skipped 🔒
Args that can’t ride the wire: streaming flags (above), the driver-resolved --config global, and clap’s own help/version actions.
values 🔒
All values of a param — arrays flatten, scalars wrap.
verbs 🔒
(name, clap spec) for every leaf verb. Hidden plumbing (gen-cli-docs) is a docs-pipeline verb, not an engine op — it stays reachable through run passthrough.
