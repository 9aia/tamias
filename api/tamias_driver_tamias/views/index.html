Module views 

Source
Expand description

views — the driver’s manifest: every ViewSpec plus the query resolvers that feed them.

Read path: all data comes from crate::data::Snapshot — one scan of the resolved tamias roots per wire op, through tamias-store-local/tamias-cache-local/tamias-registry-local/ tamias-driver exactly like the tamias CLI verbs. Nothing here proxies the tamias binary or tamias serve: the reads are in-process dir walks over .tamias-store.json records, and keeping the driver a pure reader means it can never mutate the store, cache, or registry.

Verb → view mapping:

tamias surfacepavo view
tamias list / tamias infotamias:packages table
tamias info <name>tamias:package (--param name=)
content types + tamias-driver-*tamias:types table
tamias verifytamias:verify table
tamias cache clean statstamias:cache kv
kind → driver dispatchtamias:graph graph
roots + countstamias:status kv
