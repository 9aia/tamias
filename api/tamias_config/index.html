Config port (tamias-config) — the tamias config model + format port.

YAML is the standard (tamias.yml / tamias.yaml); TOML (tamias.toml) is the supported alternative that parses into the same Config. Format impls live in tamias-config-yml / tamias-config-toml; the port never links them.
