Formats ​

YAML is the standard — tamias.yml or tamias.yaml; tamias.toml parses into the same Config. tamias config reads the first of ./tamias.yml, ./tamias.yaml, ./tamias.toml in the cwd (--file overrides); no file means defaults. The same file informs doctor's registry check (publish.default → registries.NAME).

Constraints ​

  • Token values never live in the file — token_env fields name the env var that carries them (the http client reads TAMIAS_REGISTRY_TOKEN).
  • tamias config --json dumps the effective config; tamias schema emits the JSON Schema for the package manifest (tamias.yaml), a different document.
